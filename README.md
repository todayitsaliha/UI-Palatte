# 🎨 UI-Palette.co

An intelligent, local-first color extraction and UI theme generation tool that transforms uploaded images into accessible, production-ready design systems.

Extract dominant colors, generate semantic UI palettes, validate WCAG accessibility, and preview live interface themes — all directly in the browser.

---

# 📌 Overview

UI-Palette.co is a modern frontend utility built for designers and developers who want more than random color pickers.

Instead of simply extracting hex values, the application intelligently maps image colors into functional UI roles such as:

* Background
* Surface
* Primary
* Secondary
* Accent
* Accessible text variants

The platform combines algorithmic color analysis, accessibility auditing, and live interface previews into a single premium editorial-style experience.

Everything runs locally inside the browser with zero backend infrastructure.

# 🎨 Color Logic System

The application automatically maps extracted colors into semantic UI roles.

| Semantic Role      | Behavioral Logic                       |
| ------------------ | -------------------------------------- |
| Background         | Highest or lowest luminance color      |
| Surface            | Slight tonal shift from background     |
| Primary            | Most balanced vibrant dominant color   |
| Secondary          | Supporting mid-luminance color         |
| Accent             | Highest saturation color               |
| Text On Primary    | Dynamically calculated for readability |
| Text On Background | WCAG-compliant contrast variant        |

# ♿ Accessibility Engine

UI-Palette.co automatically calculates:

* Contrast ratios
* WCAG AA compliance
* WCAG AAA compliance

If a generated theme fails accessibility standards, the system provides:

* Automatic contrast correction
* Dynamic lightness adjustment
* Accessible text color replacement

# ⚙️ Tech Stack

* **Framework:** React + Vite + TypeScript
* **Styling:** Tailwind CSS + Dynamic Inline CSS Variables
* **State Management:** Zustand / React Context
* **Color Processing:** chroma-js / culori
* **Image Analysis:** HTML5 Canvas API + Color Quantization
* **Icons:** Lucide React
* **Deployment:** Vercel
